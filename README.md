# error-VSS-on-MS-Windows-Server-2008-R2
При загрузке сервера в логи пишется ошибка:
Ошибка теневого копирования тома: Непредвиденная ошибка при вызове подпрограммы `RegOpenKeyExW(-2147483646,SYSTEM\CurrentControlSet\Services\VSS\Diag,...).. hr = 0x80070005`, Отказано в доступе.
Операция:
Инициализация модуля записи
Контекст:
Код класса модуля записи: {5382579c-98df-47a7-ac6c-98a6d7106e09}
Имя модуля записи: TermServLicensing
Код экземпляра модуля записи: {4c934598-94a8-408e-ba42-2db96043fe53}

В ветке `SYSTEM\CurrentControlSet\Services\VSS\Diag` поставил для `NETWORK SERVICE` разрешение - полный доступ, при запуске ошибка не появилась.

"С установкой роли DHCP-сервера в системе появляется новый модуль VSS - Dhcp Jet Writer , отвечающий за перечисление файлов, необходимых для работы DHCP-сервера, и соответственно, за создание их теневых копий. Данный модуль функционирует в составе службы DHCP-сервер , которая в среде Server 2008 R2 по соображениям безопасности по умолчанию работает с правами учетной записи `Network Service` , хотя в среде Server 2003 она обладала правами `Local System` . Учетная запись `Network Service` не обладает правами чтения и записи на ветку реестра `SYSTEM\CurrentControlSet\Services\VSS\Diag`, что мы и исправили. Аналогичная ситуация проявляется для роли WINS-сервер.
Изменение прав доступа на указанную ветку реестра не представляет собой угрозы безопасности."
